\# To-Do List App



A simple, clean, and interactive To-Do List app built with HTML, CSS, and vanilla JavaScript. It helps you keep track of your daily tasks, check them off as you complete them, and clear away things you've finished!



\## Features



\- Add Tasks: Type in your task and add it straight to your list.

\- Mark as Done: Click any item to strike it through and mark it completed.

\- Delete Tasks: Click the 'x' button next to any task to remove it.

\- Auto-Save: Uses browser LocalStorage so your tasks stay saved even if you refresh or close the page.

\- Smart Alerts: Reminds you if you try adding an empty item.



\## Built With



\- HTML5

\- CSS3 (Flexbox \& custom styling)

\- JavaScript (ES6 \& LocalStorage API)



\## Project Structure



\- index.html — Web page layout

\- style.css — Styling, colors, and responsive layout

\- script.js — Task logic and local storage functions



\## How to Run It



1\. Download or clone this project repository to your computer.

2\. Double-click `index.html` to open it in your favorite web browser.

3\. Start organizing your day!



\## How It Works



Whenever you add, check off, or delete a task, JavaScript updates the page and saves the exact state of your list into your browser's local storage. The next time you open the app, it pulls that saved data right back up.
